# MingCute Icons Gallery

Development gallery for the [mingcute_icons Flutter package](../README.md), not
an independent application intended for publication. Icon artwork is by
MingCute Design; this wrapper and gallery are unofficial.

## Run

From this directory:

```bash
flutter pub get
flutter run -d linux
# Or: flutter run -d chrome
```

Search by the upstream name or its snake_case identifier. Choose Regular,
Filled or Compare, change icon sizes and toggle alignment guides to inspect
the glyphs' shared em box and baseline. Tap an icon to copy its Dart usage.
The catalogue is generated by the parent package's `tool/sync_icons.py` and uses
`MingCute.regular` and `MingCute.filled` with the bundled fonts.

## Reproducible screenshots

From the repository root:

```bash
python tool/screenshots.py check
bash tool/generate_screenshots.sh --check --pixels
```

The capture mode supplies six fixed scenes, local fonts, stable viewport sizes
and fixed settings. See [the capture guide](../doc/PREVIEW.md). Do not replace
the baseline PNGs just to accept unexplained visual differences.

Web metadata identifies this gallery. Its simple four-cell geometric favicon
is an original demo asset, not the official MingCute Design logo. Regenerate it
with `python tool/generate_preview_icons.py`; no external service is used.
